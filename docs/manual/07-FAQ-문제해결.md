# 07. 자주 묻는 질문 (FAQ) & 문제 해결

## 부원 (출석 체크)

**Q. 체크인 버튼이 안 보여요.**
개인 체크인 기능이 꺼져 있는 기간입니다 ("출석은 교회 키오스크에서 진행됩니다" 안내가 표시됨). 입구 키오스크에서 출석해 주세요.

**Q. "출석 시간이 아닙니다"가 떠요.**
출석은 정해진 요일·시간(화면에 표시됨)에만 가능합니다. 시간 내 다시 시도하거나, 사정이 있으면 리더에게 수동 출석을 요청하세요.

**Q. "교회 근처에서만 출석할 수 있습니다"가 떠요.**
교회 반경 약 30m 안에서만 체크인됩니다. 교회 도착 후 다시 시도하세요. 건물 안에서 GPS가 부정확하면 창가나 입구 근처에서 다시 시도하거나 키오스크를 이용하세요.

**Q. 위치 권한을 실수로 거부했어요.**
브라우저 설정에서 이 사이트의 위치 권한을 "허용"으로 바꾼 뒤 **다시 시도**를 누르세요.
- iPhone(Safari): 설정 → Safari → 위치 / 또는 설정 → 개인정보 보호 → 위치 서비스 → Safari 웹사이트
- Android(Chrome): 주소창 자물쇠 아이콘 → 권한 → 위치

**Q. 휴대폰을 바꿨더니 저를 못 알아봐요.**
정상입니다(기기 기준으로 인식). 리더에게 "기기 연결"을 요청하면 기존 출석 기록 그대로 새 폰에 이어집니다. 새로 이름 등록을 해버렸다면 리더가 **병합**으로 합칠 수 있습니다.

**Q. 가족이 제 폰으로도 출석할 수 있나요?**
한 기기는 한 명에게 연결됩니다. 가족은 본인 기기를 쓰거나 키오스크에서 출석해 주세요.

**Q. "승인 대기 중"이라고 떠요.**
등록 승인제가 켜져 있는 경우입니다. 관리자가 승인하면 자동으로 출석까지 완료됩니다. 오래 걸리면 리더에게 말씀해 주세요.

**Q. 인터넷이 안 되는데 체크인을 눌렀어요.**
"오프라인 — 대기열에 저장됨"이 떴다면 걱정 마세요. 인터넷이 연결되는 순간 자동으로 출석 처리됩니다.

## 리더 / 새가족팀

**Q. 관리자 로그인이 안 돼요.**
- Google 로그인: 본인 이메일이 멤버 정보에 등록되어 있고 관리자 역할이 부여되어 있어야 합니다 → 최고관리자에게 확인 요청.
- 비밀번호 입장: ① 비밀번호 확인, ② **본인 기기가 본인 멤버에 연결**되어 있는지 확인(기기 탭에서 연결), ③ 역할 부여 여부 확인. 키오스크 명단(ROSTER) 기기로는 불가.

**Q. 다른 동산/부서 멤버가 안 보여요.**
리더·새가족팀은 지정된 부서·동산 범위만 봅니다. 범위 변경은 최고관리자에게 요청하세요. (여름 모드에는 대학부·청년부가 합동으로 보입니다)

**Q. 출석을 잘못 찍었어요. 지울 수 있나요?**
「멤버」 → 해당 멤버 → 출석 이력 펼치기 → 해당 날짜 삭제. 또는 「출석부」 로그에서 확인 후 같은 방법으로 삭제.

**Q. 지난주 출석을 빠뜨렸어요.**
「출석부」 → **일괄 출석** → 날짜 선택 → 멤버 선택 → 저장.

**Q. 같은 사람이 두 명으로 보여요.**
「멤버」에서 한쪽 카드 → **병합**. 출석 기록이 합쳐지고 한 명만 남습니다. 되돌릴 수 없으니 이름·기록을 꼭 확인 후 진행하세요.

**Q. "동산 이동" 버튼이 안 보이거나 안 돼요.**
새가족팀 역할이거나, 본인이 동산지기/부동산지기로 지정된 리더는 사용할 수 없습니다.

**Q. 출석부를 엑셀/PDF로 뽑고 싶어요.**
「출석부」 → **내보내기** → Excel / PDF / 카카오톡 요약 중 선택.

## 최고관리자

**Q. 출석 전체 삭제 요청이 왔는데 어디서 처리하나요?**
「관리자」 탭 하단의 삭제 요청 목록에서 **승인 후 삭제** 또는 **거절**. 승인 전 반드시 백업을 받으세요.

**Q. 실수로 데이터를 망쳤어요.**
최근 백업 파일이 있다면 「관리자」 → **복원**. 백업 시점 이후 기록은 사라지므로 신중히. 누가 무엇을 했는지는 **감사 로그**에서 확인할 수 있습니다.

**Q. 마지막 최고관리자를 제거하려니 안 돼요.**
의도된 안전장치입니다. 새 최고관리자를 먼저 추가한 뒤 제거하세요.

**Q. 여름이 끝났는데 동산이 이상해요.**
「설정」에서 여름 모드 OFF → 「동산」에서 부서별 동산 이름 확인 → 「멤버」 동산 일괄 이동으로 재배치.

## 공통

**Q. 화면이 영어로/한국어로 바뀌었어요.**
우측 상단 `EN`/`KO` 버튼으로 전환됩니다. 기기별로 저장됩니다.

**Q. 새로고침했더니 첫 화면으로 돌아갔어요.**
의도된 동작입니다(키오스크 화면만 새로고침 시 유지). 관리자 화면은 다시 로그인해 들어가세요.

**Q. 버그를 발견했어요 / 기능 제안이 있어요.**
임원(시스템 담당자)에게 화면 캡처와 함께 알려주세요. GitHub 저장소(shrlak/kccp) 이슈로도 접수 가능합니다.
