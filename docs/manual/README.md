## 빠른 시작

- **부원**: 휴대폰 브라우저로 앱에 접속 → **체크인** 버튼 → 끝. (첫 사용 시 이름 등록 한 번 필요)
- **리더/팀장/임원**: 첫 화면 우측 하단의 **관리자** 링크 → Google 계정으로 로그인 (또는 비밀번호 입장) → 관리자 화면.
- **주일 현장 담당**: 관리자 로그인 후 **키오스크** 버튼 → 태블릿을 입구에 비치.

## 역할 한눈에 보기

| 역할 | 한국어 표기 | 한 줄 요약 |
|---|---|---|
| super_admin | 최고관리자 | 모든 기능 + 설정·권한·승인·백업 관리 |
| leader | 리더 | 자기 부서·동산 범위에서 출석/멤버 관리 |
| welcoming | 새가족팀 | 새가족 등록·관리 중심, 출석 처리 가능 |
| pastor | 목사님 | 전체 열람 가능, 수정은 불가(읽기 전용) |
| (없음) | 일반 부원 | 본인 출석 체크만 |

> 참고: **동산지기/부동산지기**는 멤버 카드에 표시되는 👑/⭐ 배지(명예 표시)이며,
> 위의 관리자 역할(권한)과는 별개입니다. 동산지기라고 해서 관리자 화면에 들어갈 수 있는 것은 아닙니다.
