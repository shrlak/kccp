## 00. 시스템 개요

### 이 시스템은 무엇인가요?

KCCP 출석 시스템은 대학·청년부 주일 출석을 **종이 없이** 관리하는 웹 앱입니다.
설치할 앱은 없고, 휴대폰·태블릿·컴퓨터의 브라우저로 접속하면 됩니다.

- **앱 주소**: https://shrlak.github.io/kccp/
- **언어**: 한국어/영어 전환 가능 (우측 상단 `EN`/`KO` 버튼)
- **다크 모드**: 우측 상단 ☀/☾ 버튼
- **휴대폰 홈 화면에 추가**해 두면 앱처럼 쓸 수 있습니다 (브라우저 메뉴 → "홈 화면에 추가")

### 화면 구성 (3가지 입구)

1. **첫 화면 (랜딩)** — 누구나 볼 수 있는 화면. 공지사항과 **체크인** 버튼이 있습니다.
2. **키오스크** (`키오스크` 버튼) — 교회 입구 태블릿용 큰 버튼 화면. 담당자가 이름을 눌러 출석 처리합니다.
3. **관리자 화면** (첫 화면의 **관리자** 링크) — 리더/팀장/임원이 출석부·멤버·통계를 관리합니다.

### 꼭 알아야 할 용어

| 용어 | 뜻 |
|---|---|
| **부서** | 대학부 / 청년부 / EM / Adult Ministry |
| **동산** | 부서 안의 소그룹 (예: 동산1, 동산2) |
| **동산지기 / 부동산지기** | 동산의 인도자/부인도자. 멤버 카드에 👑/⭐ 배지로 표시됩니다. **관리자 권한과는 별개**입니다. |
| **새가족** | 이번 학기에 처음 등록한 멤버. 🌟 표시가 붙고 새가족 탭에서 따로 관리됩니다. |
| **기기(디바이스)** | 출석 체크에 쓰는 휴대폰/브라우저. 시스템이 자동으로 기기를 기억해서 본인을 알아봅니다. |
| **합동(여름 모드)** | 여름 기간에 대학부+청년부 동산을 합쳐서 운영하는 모드. 리더의 관리 범위도 두 부서로 넓어집니다. |

### 출석은 어떻게 인정되나요?

출석 체크에는 두 가지 방법이 있습니다.

1. **개인 휴대폰 체크인** — 부원이 본인 폰에서 체크인 버튼을 누릅니다. 다음 조건을 만족해야 합니다.
   - **요일·시간**: 설정된 출석 가능 시간 안에서만 가능 (예: 주일 오후 1시–3시)
   - **위치**: 교회 반경 약 30m 안에서만 가능 (위치 권한 허용 필요)
2. **키오스크/관리자 수동 출석** — 담당자가 키오스크에서 이름을 누르거나, 관리자 화면에서 수동 출석 처리합니다. **시간·위치 제한 없이** 가능합니다.

> 개인 체크인 기능 자체를 켜고 끄는 것은 최고관리자가 설정에서 결정합니다.
> 꺼져 있으면 첫 화면에 "출석은 교회 키오스크에서 진행됩니다"라고 표시됩니다.

### 관리자 로그인 방법

첫 화면 → **관리자** 링크 → 로그인.

1. **Google 로그인 (권장)** — "Sign in with Google" 버튼. 시스템에 등록된 이메일이고 관리자 역할이 부여된 경우에만 입장됩니다.
2. **비밀번호 입장 (보조 수단)** — "비밀번호로 입장"을 펼쳐 마스터 비밀번호 입력. 단, **본인 기기가 멤버에 연결되어 있고 그 멤버에게 관리자 역할이 있어야** 합니다.
   - 비밀번호는 문서에 적지 않습니다. 필요하면 임원에게 직접 문의하세요.
   - 키오스크용 명단 기기(ROSTER 기기)로는 관리자 로그인이 불가합니다.

로그인하면 본인 역할에 맞는 탭만 보입니다. 권한이 없는데 입장이 안 되면 → 최고관리자에게 역할 등록을 요청하세요 (05 최고관리자 매뉴얼 참고).

### 역할별 권한표

| 기능 | 최고관리자 | 리더 | 새가족팀 | 목사님 |
|---|:---:|:---:|:---:|:---:|
| 보이는 범위 | 전체 | 자기 부서·동산 | 자기 부서·동산 | 전체 |
| 오늘/출석부/멤버/통계/새가족 탭 | ✓ | ✓ | ✓ | ✓ (열람만) |
| 수동 출석 처리, 키오스크 사용 | ✓ | ✓ | ✓ | ✗ |
| 멤버 정보 수정 | ✓ | ✓ | ✓ | ✗ |
| 동산 일괄 이동 | ✓ | ✓* | ✗ | ✗ |
| 출석 기록 전체 삭제 | 즉시 가능 | 요청만* | 요청만* | ✗ |
| 기기 탭 (기기 등록/연결) | ✓ | ✓ | ✓ | ✗ |
| 관리자 탭 (권한·승인·감사로그·백업) | ✓ | ✗ | ✗ | ✗ |
| 동산 탭 (동산 이름·동산지기 지정) | ✓ | ✗ | ✗ | ✗ |
| 설정 탭 (출석 시간·공지·모드) | ✓ | ✗ | ✗ | ✗ |

\* 본인이 동산지기/부동산지기로 지정된 경우에는 불가.

### 데이터와 안전장치

- 모든 데이터는 클라우드 데이터베이스(Supabase)에 저장되고, 외부에서는 직접 접근할 수 없습니다.
- 관리자가 하는 주요 작업(설정 변경, 멤버 수정/병합, 출석 삭제, 권한 부여 등)은 **감사 로그**에 모두 기록됩니다.
- 출석 기록 전체 삭제는 리더가 단독으로 할 수 없고, **최고관리자의 승인**이 필요합니다.
- 최고관리자는 전체 데이터를 **백업 파일(JSON)** 로 내려받고 복원할 수 있습니다.
- 인터넷이 잠시 끊겨도 체크인은 기기에 **대기열로 저장**되었다가 연결되면 자동 동기화됩니다.

## 01. 부원용 안내 — 휴대폰으로 출석 체크하기

**대상**: 모든 부원 (관리자 권한 없음)

### 주일 출석 체크 (평소 사용법)

1. 휴대폰 브라우저로 접속: **https://shrlak.github.io/kccp/**
   - 홈 화면에 추가해 두면 다음부터 한 번에 열 수 있어요.
2. **체크인** 버튼을 누릅니다.
3. 위치 권한을 물어보면 **허용**해 주세요. (교회 근처인지 확인하는 용도로만 사용됩니다)
4. 초록색 ✓ 와 함께 이름, 시간, 누적 출석 횟수가 나오면 완료!
   - 첫 출석이면 🌟 금색 화면으로 특별히 환영해 드립니다.

### 처음 사용할 때 — 이름 등록 (딱 한 번)

처음 체크인하면 "이 기기에 이름이 등록되지 않았습니다"라는 안내가 나옵니다.

1. **이름 등록** 버튼을 누릅니다.
2. 이름, 부서(대학부/청년부 등), 동산을 입력하고 저장합니다.
3. 등록 승인제가 켜져 있는 경우 "승인 대기 중"이 표시되며, 관리자가 승인하면 출석이 완료됩니다.

이후로는 같은 휴대폰(같은 브라우저)에서 체크인만 누르면 자동으로 본인을 알아봅니다.

> **주의**: 시스템은 "브라우저"를 기억합니다. 휴대폰을 바꾸거나, 다른 브라우저/시크릿 모드를 쓰면
> 새 기기로 인식됩니다. 그럴 땐 리더에게 "기기 다시 연결해 주세요"라고 요청하면 출석 기록이 그대로 이어집니다.

### 이런 화면이 나오면?

| 화면 | 의미 | 해결 |
|---|---|---|
| ✓ 출석 완료 (초록) | 정상 출석 | 없음 😊 |
| 📋 이미 출석했습니다 (주황) | 오늘 이미 체크인함 | 없음 |
| ⏰ 출석 가능한 요일이 아닙니다 / 출석 시간이 아닙니다 | 출석 시간대가 아님 | 정해진 시간(화면에 표시됨)에 다시 시도 |
| 📍 위치 정보가 필요합니다 | 위치 권한 거부됨 | 브라우저 설정에서 위치 허용 후 **다시 시도** |
| 📍 교회 근처에서만 출석할 수 있습니다 | 교회에서 너무 멀리 있음 | 교회 도착 후 다시 시도 |
| 📡 오프라인 — 대기열에 저장됨 | 인터넷 연결 없음 | 그대로 두면 연결 시 자동으로 출석 처리됨 |

### 휴대폰이 없거나 안 될 때

교회 입구의 **키오스크(태블릿)** 에서 담당자에게 이름을 말씀해 주세요. 이름을 눌러 출석 처리해 드립니다.
방문자(게스트)나 처음 오신 분도 키오스크에서 바로 등록할 수 있습니다.

### 기타

- **언어 전환**: 우측 상단 `EN`/`KO` 버튼.
- **다크 모드**: 우측 상단 ☀/☾ 버튼.
- **공지사항**: 첫 화면의 금색 "공지" 박스에 표시됩니다.
- 개인정보(이름, 부서, 동산, 출석 기록)는 부서 운영 목적으로만 사용됩니다.

## 02. 리더용 매뉴얼

**대상**: `리더(leader)` 역할이 부여된 동산 리더·팀장

리더는 **본인 부서 + 본인 동산** 범위의 멤버만 보고 관리할 수 있습니다.
여름 모드(합동) 기간에는 대학부·청년부가 합쳐져 두 부서를 함께 보게 됩니다.

### 로그인

1. 앱 첫 화면 → 우측 하단 **관리자** 링크.
2. **Google 로그인** (본인 이메일이 멤버 정보에 등록되어 있어야 함) 또는 **비밀번호로 입장**.
3. 로그인이 안 되면: ① 최고관리자에게 리더 역할 등록 요청, ② Google 로그인 시 본인 이메일 등록 요청, ③ 비밀번호 입장 시 본인 기기가 멤버에 연결되어 있는지 확인.

로그인하면 좌측에 탭 메뉴(레일)가 보입니다: **오늘 · 출석부 · 멤버 · 통계 · 새가족 · 기기**.

---

### 「오늘」 탭 — 주일 실시간 출석 확인

- 오늘 체크인한 멤버가 실시간 목록으로 보입니다 (이름, 시간, 부서/동산, 👑/⭐ 배지).
- 상단에 **이번 주 vs 지난주** 출석 비교(↑↓→)가 표시됩니다.
- 내 동산만 보는 경우 **동산 대시보드**가 나옵니다:
  - 출석 인원 / 전체 인원
  - 최근 4주 평균 출석률 (초록 80%↑ / 주황 60–80% / 빨강 60%↓)
  - **오늘 결석자 명단** — 심방·연락 리스트로 활용하세요.

##### 수동 출석 처리
휴대폰이 없거나 체크인을 놓친 부원은:
1. 「오늘」 탭의 **수동 출석** 버튼 → 이름 검색 → 선택.
2. 시간·위치 제한 없이 바로 출석 처리됩니다. (수동 처리로 기록에 표시됨)

---

### 「출석부」 탭 — 출석 시트와 기록

- **그리드 보기**: 행=멤버, 열=날짜, ✓/· 로 출석 여부 표시. 맨 오른쪽에 누적 횟수.
- **로그 보기**: 최신순 출석 기록. 항목을 누르면 상세(첫 출석 🌟 표시 포함).
- 부서/동산 필터, 이름 정렬 가능.

##### 지난 날짜 출석 일괄 입력
출석 체크를 놓친 주가 있을 때:
1. **일괄 출석** 버튼 → 날짜 선택 → 멤버 여러 명 검색·선택 → 저장.

##### 내보내기 (보고용)
**내보내기** 메뉴에서:
- **Excel (.xlsx)** — 동산별 O/X 양식의 출석부 + 전체 로그.
- **카카오톡 요약** — 오늘 출석 요약을 클립보드에 복사 → 단톡방에 붙여넣기.
- **PDF 보고서** — 인쇄 대화상자가 열리며 학기별 통계가 포함된 보고서 출력/저장.

##### ⚠️ 출석 전체 삭제
- 리더는 직접 삭제할 수 없고 **삭제 요청**만 보낼 수 있습니다. 최고관리자가 승인해야 실제로 삭제됩니다.
- 본인이 동산지기/부동산지기로 지정된 경우에는 요청 자체가 불가합니다.

---

### 「멤버」 탭 — 멤버 정보 관리

내 범위의 멤버가 카드로 표시됩니다 (이름, 부서/동산, 👑/⭐ 배지, 새가족 🌟 표시). 검색 가능.

##### 멤버 수정
카드 클릭 → 수정 대화상자:
- 이름, 부서, 동산, 직분(visitor/pastor/elder/deacon/mentor), 성별, 전화번호, 카카오톡 ID, 생일, 메모, 새가족 여부.
- **출석 이력**: 펼쳐서 날짜별 출석을 직접 추가/삭제할 수 있습니다.

##### 멤버 병합 (중복 정리)
같은 사람이 두 명으로 등록된 경우(예: 명단 등록 + 본인 폰 등록):
1. 수정 대화상자의 **병합** 버튼 → 합칠 대상 멤버 선택.
2. 기기와 출석 기록이 대상 멤버로 옮겨지고 원본은 삭제됩니다. **되돌릴 수 없으니** 신중히!

##### 동산 일괄 이동
학기 초 동산 편성 시:
1. **동산 이동** 버튼 → 선택 모드 진입 → 멤버 여러 명 체크.
2. 드롭다운에서 동산 선택 → **이 동산으로** (또는 **동산에서 제외**).
3. 본인이 동산지기/부동산지기인 리더는 이 기능을 쓸 수 없습니다.

---

### 「통계」 탭

- **추이 그래프**: 최근 주일별 출석 인원 변화.
- **부서 비교** 막대그래프.
- **월별 요약** (주일 수 / 출석 인원 / 첫 출석), **학기별 요약** (상반기 1/1–6/30, 하반기 7/1–12/31).
- **주간 요약 + 복사 버튼**: 가장 최근 주일 요약을 카톡용으로 복사.

### 「새가족」 탭

내 범위의 새가족 현황을 봅니다. 교육 1·2주차 체크, 심방 요청 🙏 표시 등.
자세한 내용은 03 새가족팀 매뉴얼과 동일합니다.

### 「기기」 탭 — 부원 휴대폰 연결

부원이 휴대폰을 바꿨거나 처음 연결할 때:

- **기기 등록**: 기기 ID 입력(부원 폰의 첫 화면 하단에서 확인 가능 / "이 기기" 자동 입력) + 새 멤버 이름·부서·동산 입력 → 새 멤버 생성과 동시에 기기 연결.
- **기기 연결**: 기기 ID + **기존 멤버 검색** → 연결. 기존 출석 기록이 그대로 이어집니다.
- 명단용(ROSTER) 자리표시 멤버가 있던 경우, 실제 기기 연결 시 자동으로 합쳐집니다.

### 키오스크 사용

상단의 **키오스크** 버튼으로 키오스크 모드에 들어갈 수 있습니다.
운영 방법은 06 키오스크 운영 가이드를 보세요.

### 리더 주간 루틴 (추천)

2. **예배 후**: 「오늘」 탭에서 결석자 확인 → 수동 출석 누락분 처리 → 결석자 연락.
3. **주중**: 「새가족」 탭에서 새가족 교육·심방 진행 상황 체크.
4. **월말/학기말**: 「출석부」 내보내기로 보고서 제출, 「통계」로 추이 확인.

## 03. 새가족팀용 매뉴얼

**대상**: `새가족팀(welcoming)` 역할이 부여된 팀원

새가족팀은 리더와 거의 같은 화면(오늘 · 출석부 · 멤버 · 통계 · 새가족 · 기기)을 보며,
**새가족 등록과 정착 관리**가 핵심 업무입니다. 보이는 범위는 본인에게 지정된 부서·동산 기준입니다.

### 로그인

02 리더용 매뉴얼의 로그인 방법과 동일합니다.
(첫 화면 → **관리자** → Google 로그인 또는 비밀번호 입장. 권한 문제는 최고관리자에게 문의)

---

### 핵심 업무 1: 새가족 현장 등록 (주일)

처음 오신 분은 **키오스크**에서 바로 등록하는 것이 가장 좋습니다.

1. 키오스크 하단의 **✝️ 새가족 등록** 버튼.
2. 등록 카드 작성: 이름, 부서, 동산, 성별, 전화번호, 카카오톡 ID, 생일, 세례 여부, 학교, 신앙 기간, 등록일, **심방 요청** 여부.
3. 저장하면 멤버 생성 + **오늘 출석(첫 출석 🌟)** 이 자동으로 함께 기록됩니다.

> 아직 등록을 원치 않는 단순 방문자는 **👋 게스트 체크인**으로 이름만 받아 출석만 기록하세요.
> 나중에 등록을 원하면 그때 새가족 등록을 하면 됩니다.

키오스크 전반의 사용법은 06 키오스크 운영 가이드 참고.

### 핵심 업무 2: 「새가족」 탭 — 정착 관리

- **이번 학기 새가족 목록**: 이번 학기에 등록한 멤버가 자동으로 모입니다 (학기 배지 표시, 예: "2026 봄학기").
- 각 새가족 행에서:
  - **교육 1주차 / 교육 2주차** 체크박스 — 새가족 교육 수료 여부를 표시.
  - **🙏 심방 요청** 표시 — 등록 시 심방을 요청한 분. 목사님·리더와 공유해 심방을 진행하세요.
  - 등록일, 전화번호 표시.
- **월별 등록 현황**: 지난 학기 새가족들이 월별로 정리되어 보입니다.

### 핵심 업무 3: 새가족 정보 보완

「멤버」 탭에서 해당 멤버 카드 클릭 → 수정:
- 누락된 연락처, 생일, 카카오톡 ID, 메모(기도제목 등) 입력.
- 새가족 기간이 끝나면 **새가족 체크박스를 해제**해 일반 멤버로 전환.
- 본인 폰으로도 출석하기 시작해 중복 멤버가 생겼다면 **병합** 기능으로 정리 (출석 기록이 합쳐짐, 되돌릴 수 없음).

### 그 외 가능한 일

- 「오늘」 탭에서 **수동 출석** 처리 (새가족이 체크인을 어려워할 때).
- 「기기」 탭에서 새가족의 휴대폰을 멤버에 **연결** — 다음 주부터는 본인 폰으로 직접 체크인할 수 있게 해주세요.
- 「통계」 탭의 월별/학기별 **첫 출석(새가족) 수** 확인 — 새가족 보고에 활용.

### 새가족팀이 할 수 없는 일

- 동산 일괄 이동, 출석 전체 삭제(요청만 가능), 설정/동산/관리자 탭 접근.

---

### 새가족 응대 흐름 (추천)

1. **주일**: 새 얼굴 발견 → 인사 → 키오스크 ✝️ 새가족 등록 (심방 요청 여부 꼭 확인).
2. **당일/주중**: 「새가족」 탭에서 등록 확인 → 환영 연락 (전화번호/카톡 ID 활용).
3. **교육 기간**: 교육 1·2주차 진행 시마다 체크박스 표시.
4. **다음 주일**: 본인 휴대폰으로 체크인하도록 안내 (기기 연결 도와주기).
5. **학기말**: 새가족 정착 현황을 통계와 함께 보고.

## 04. 목사님용 안내

**대상**: `목사님(pastor)` 역할

목사님 계정은 **전체 부서·동산을 열람**할 수 있는 읽기 전용 계정입니다.
실수로 데이터가 바뀔 걱정 없이 모든 현황을 안전하게 보실 수 있습니다.

### 로그인

1. 앱 첫 화면(https://shrlak.github.io/kccp/) → 우측 하단 **관리자** 링크.
2. **Google 로그인** 버튼 → 본인 Google 계정 선택. (등록된 이메일이면 바로 입장됩니다)
3. 잘 안 되면 임원에게 문의해 주세요.

### 보실 수 있는 화면

##### 「오늘」 — 오늘 출석 현황
- 오늘 체크인한 부원 명단(이름, 시간, 부서/동산)과 지난주 대비 증감(↑↓→).

##### 「출석부」 — 전체 출석 기록
- 멤버×날짜 표 형태의 출석부 (✓ 출석 / · 결석, 누적 횟수).
- 최신순 출석 로그. 첫 출석은 🌟로 표시됩니다.
- **내보내기**: Excel 출석부, PDF 보고서를 내려받아 보실 수 있습니다.

##### 「멤버」 — 전체 멤버 명단
- 부서·동산별 멤버, 동산지기 👑/부동산지기 ⭐ 배지, 새가족 🌟 표시.
- 카드를 열어 연락처·메모 등 상세 정보를 보실 수 있습니다 (수정은 불가).

##### 「통계」 — 출석 추이와 요약
- 주일별 출석 추이 그래프, 부서별 비교.
- 월별·학기별 요약 (주일 수, 출석 인원, 첫 출석 수).

##### 「새가족」 — 새가족 현황
- 이번 학기 등록 새가족 명단, 교육 1·2주차 진행 상황.
- **🙏 심방 요청** 표시가 있는 분들을 확인하시고 심방 일정에 참고해 주세요.

##### 「동산」 — 동산 구성 열람
- 각 부서의 동산 구성과 동산지기/부동산지기 지정 현황.

### 참고

- 출석 처리(체크인), 멤버 수정, 설정 변경은 목사님 계정에서 불가능합니다 — 필요한 변경은 임원에게 요청해 주세요.
- 우측 상단에서 한국어/영어 전환(`EN`/`KO`)과 다크 모드(☀/☾)를 쓰실 수 있습니다.

## 05. 최고관리자(임원) 매뉴얼

**대상**: `최고관리자(super_admin)` — 회장단·임원·시스템 총괄

최고관리자는 모든 기능을 쓸 수 있고, 리더에게 없는 세 개의 탭이 추가로 보입니다:
**관리자 · 동산 · 설정**. 리더 공통 기능(오늘/출석부/멤버/통계/새가족/기기)은
02 리더용 매뉴얼을 보세요. 이 문서는 최고관리자 전용 기능을 다룹니다.

---

### 「설정」 탭

##### 출석 가능 시간
- **요일 선택**: 일–토 버튼 토글 (최소 1개).
- **시간**: 시작/종료 시각(24시간제). 예: 13:00–15:00.
- 이 시간 밖에는 개인 휴대폰 체크인이 차단됩니다 (키오스크/수동 출석은 항상 가능).

##### 공지사항
- 입력한 내용이 첫 화면과 체크인 결과 화면의 금색 "공지" 박스에 표시됩니다.

##### 모드 3종
| 모드 | 켜면 |
|---|---|
| **여름 모드 (합동)** | 대학부·청년부 동산이 합쳐지고, KM 리더들이 두 부서를 모두 보게 됩니다. 동산 탭도 합동 명단으로 전환. |
| **개인 체크인** | 첫 화면에 체크인 버튼이 나타나 부원이 직접 출석할 수 있습니다. 끄면 키오스크 전용 운영. |
| **데모 모드** | 요일·시간·위치 제한이 전부 해제됩니다. **시연/테스트용 — 평상시에는 반드시 꺼두세요.** |

---

### 「동산」 탭

##### 동산 이름 관리
- 부서별(대학부/청년부/EM/Adult Ministry)로 동산 이름 목록을 추가/삭제.
- **여름 모드 중에는** 합동 명단 하나로 편집하며, 대학부·청년부 양쪽에 동일하게 적용됩니다 (☀️ 경고 배너 표시).
- **저장** 버튼을 눌러야 반영됩니다.

##### 동산지기 👑 / 부동산지기 ⭐ 지정
- 부서+동산별로 멤버를 검색해 동산지기/부동산지기를 지정.
- 멤버 카드와 「오늘」 목록에 배지로 표시됩니다.
- **표시용 배지일 뿐 권한과 무관**합니다. 단, 동산지기/부동산지기로 지정된 리더는 동산 일괄 이동과 출석 삭제 요청이 막힙니다 (이해충돌 방지).

---

### 「관리자」 탭 — 권한·승인·감사·백업

##### 관리자 명단 (역할 부여/회수)
- 현재 관리자 목록: 이름, 역할(최고관리자/리더/목사님/새가족팀), 부서, 동산, 사역.
- **관리자 추가**: 멤버 검색 → 역할 선택 → 범위(부서/동산) 지정.
  - 리더·새가족팀은 반드시 부서·동산 범위를 지정하세요 — 그 범위만 보게 됩니다.
  - Google 로그인을 쓰게 하려면 「멤버」 탭에서 해당 멤버에 **이메일**도 등록해 주세요.
- **제거**: 역할 회수. 마지막 남은 최고관리자는 제거할 수 없습니다(잠금 방지).

##### 등록 승인 대기열
- **등록 승인제** 스위치를 켜면, 부원의 휴대폰 자가등록이 즉시 멤버가 되지 않고 대기열로 들어옵니다.
- 대기 항목(기기 ID, 이름, 부서, 동산, 신청 시각)을 **승인**(멤버 생성·연결) 또는 **거절**.
- 관리자 탭 아이콘에 대기 건수 배지가 표시됩니다.

##### 출석 전체 삭제 — 승인 절차
- 리더/새가족팀이 보낸 삭제 요청이 여기 표시됩니다 (요청자, 시각).
- **승인 후 삭제**: 전체 출석 기록 삭제 (복구 불가!) / **거절**: 요청만 폐기.
- 최고관리자 본인은 「출석부」 탭에서 즉시 삭제할 수 있습니다 — 학기 리셋 등 꼭 필요할 때만, **반드시 백업을 먼저** 받으세요.

##### 감사 로그
- **감사 로그 불러오기** 버튼 → 최근 100건의 관리 작업 (시각, 작업, 관리자, 상세).
- 로그인, 설정 변경, 멤버 수정/병합, 기기 등록/연결, 출석 추가/삭제, 권한 변경, 복원 등 모든 민감 작업이 기록됩니다. 문제가 생기면 여기서 먼저 추적하세요.

##### 백업 / 복원
- **백업 다운로드**: 전체 데이터 JSON 스냅샷 (`kccp-backup-날짜.json`). **매주 또는 큰 작업 전마다** 받아두기를 권장합니다.
- **복원**: 백업 파일 선택 → 2단계 확인 → **모든 데이터가 백업 시점으로 덮어쓰기**됩니다. 비상시에만 사용.

### 자주 하는 운영 작업 절차

##### 새 리더 임명
1. 그 사람이 멤버로 등록되어 있는지 「멤버」에서 확인 (없으면 「기기」에서 등록).
2. Google 로그인용 이메일을 멤버 정보에 입력.
3. 「관리자」 → 관리자 추가 → 역할 `리더` + 부서·동산 범위 지정.
4. 본인에게 로그인 방법 안내 (02 리더용 전달).

##### 학기 전환 (예: 여름 합동 시작)
1. 백업 다운로드.
2. 「설정」에서 여름 모드 ON.
3. 「동산」에서 합동 동산 이름 정리, 동산지기 재지정.
4. 「멤버」에서 동산 일괄 이동으로 부원 배치.

##### 출석 시간 임시 변경 (특별 행사)
1. 「설정」에서 요일/시간 변경 → 저장.
2. 행사 후 원래대로 복구. (현장에서만 받을 거면 개인 체크인을 끄고 키오스크로 운영해도 됩니다)

##### 부원이 폰을 바꿨어요
「기기」 탭 → **기기 연결** → 새 기기 ID + 기존 멤버 검색 → 연결. 출석 기록 유지됨.

##### 중복 멤버 정리
「멤버」 → 카드 열기 → **병합** → 남길 멤버 선택. (되돌릴 수 없음 — 백업 먼저!)

### 운영 수칙 (권장)

- 데모 모드는 시연 직후 바로 끄기.
- 전체 삭제·복원·병합 전에는 항상 백업.
- 최고관리자는 최소 2명 유지 (한 명이 연락 두절돼도 운영 가능하도록).
- 마스터 비밀번호는 단톡방에 올리지 말고 필요한 사람에게 개별 전달. 유출 의심 시 시스템 담당자에게 변경 요청.
- 학기마다 「관리자」 명단을 점검해 더 이상 섬기지 않는 사람의 역할 회수.

## 06. 키오스크 운영 가이드

**대상**: 주일 출석 데스크 담당자 (관리자 권한 필요 — 리더/새가족팀/최고관리자. 목사님 계정은 키오스크 불가)

키오스크는 교회 입구 태블릿에 띄워 놓는 **큰 버튼 출석 화면**입니다.
부원 이름을 누르면 바로 출석 처리되며, 시간·위치 제한이 없습니다.

### 예배 전 세팅

1. 태블릿에서 앱 접속 → **관리자** → 로그인.
2. 상단의 **키오스크** 버튼 → 전체 화면 키오스크 진입.
3. 헤더에 "출석 키오스크"와 오늘 출석 인원이 보이면 준비 완료.
4. 태블릿을 입구 데스크에 비치. (화면 자동 잠금은 길게 설정 권장)

> 키오스크 화면은 새로고침해도 유지됩니다. 명단은 30초마다 자동 갱신됩니다.

### 기본 사용법 — 이름 눌러 출석

- 명단이 부서별로 구분되어 표시됩니다 (대학부=노랑, 청년부=파랑, 기타=회색).
- 부원 **이름 버튼을 탭** → 출석 완료 표시.
- 이미 출석한 부원은 **초록 체크**가 붙어 있고, 다시 누르면 "이미 출석" 안내가 뜹니다.
- 사람이 많으면 상단 **🔍 이름 검색** 칸에 입력해 바로 찾으세요.

### 하단 버튼 2개

##### 👋 게스트 체크인
- 일회성 방문자용. 이름만 입력하면 오늘 출석이 방문자(visitor)로 기록됩니다.
- 정식 멤버가 만들어지지 않으므로 "그냥 한번 와본" 분께 부담 없이 사용하세요.

##### ✝️ 새가족 등록
- 정식 등록을 원하는 새가족용. 등록 카드(이름, 부서, 동산, 성별, 연락처, 카톡 ID, 생일, 세례, 학교, 신앙 기간, 등록일, 심방 요청)를 작성합니다.
- 저장 시 멤버 생성 + **오늘 첫 출석 🌟** 이 자동 기록되고, 「새가족」 탭 관리 목록에 들어갑니다.
- 가능하면 새가족팀과 함께 응대하세요 (03 새가족팀 매뉴얼).

### 키오스크 종료

- 헤더의 **종료** 버튼 → 관리자 비밀번호 입력 → 종료.
- 비밀번호를 요구하는 이유: 부원이 실수로(또는 장난으로) 키오스크를 빠져나가는 것을 막기 위해서입니다.

### 문제 해결

| 상황 | 조치 |
|---|---|
| 명단에 이름이 없음 | 👋 게스트로 우선 출석 처리 → 예배 후 관리자 화면 「기기」/「멤버」에서 정식 등록 |
| 인터넷 끊김 | 잠시 후 자동 복구. 안 되면 와이파이 확인 후 새로고침 |
| 잘못 눌러 다른 사람 출석 처리됨 | 관리자 화면 「멤버」 → 해당 멤버 → 출석 이력에서 오늘 기록 삭제 |
| 화면이 잠겼거나 닫힘 | 다시 접속해 관리자 로그인 → 키오스크 재진입 |

### 예배 후 마무리

1. 키오스크 종료 (비밀번호).
2. 관리자 화면 「오늘」 탭에서 출석 누락 확인 → 수동 출석 보정.
3. 필요 시 「출석부」 → 내보내기 → **카카오톡 요약** 복사해 보고.

## 07. 자주 묻는 질문 (FAQ) & 문제 해결

### 부원 (출석 체크)

**Q. 체크인 버튼이 안 보여요.**
개인 체크인 기능이 꺼져 있는 기간입니다 ("출석은 교회 키오스크에서 진행됩니다" 안내가 표시됨). 입구 키오스크에서 출석해 주세요.

**Q. "출석 시간이 아닙니다"가 떠요.**
출석은 정해진 요일·시간(화면에 표시됨)에만 가능합니다. 시간 내 다시 시도하거나, 사정이 있으면 리더에게 수동 출석을 요청하세요.

**Q. "교회 근처에서만 출석할 수 있습니다"가 떠요.**
교회 반경 약 30m 안에서만 체크인됩니다. 교회 도착 후 다시 시도하세요. 건물 안에서 GPS가 부정확하면 창가나 입구 근처에서 다시 시도하거나 키오스크를 이용하세요.

**Q. 위치 권한을 실수로 거부했어요.**
브라우저 설정에서 이 사이트의 위치 권한을 "허용"으로 바꾼 뒤 **다시 시도**를 누르세요.
- iPhone(Safari): 설정 → Safari → 위치 / 또는 설정 → 개인정보 보호 → 위치 서비스 → Safari 웹사이트
- Android(Chrome): 주소창 자물쇠 아이콘 → 권한 → 위치

**Q. 휴대폰을 바꿨더니 저를 못 알아봐요.**
정상입니다(기기 기준으로 인식). 리더에게 "기기 연결"을 요청하면 기존 출석 기록 그대로 새 폰에 이어집니다. 새로 이름 등록을 해버렸다면 리더가 **병합**으로 합칠 수 있습니다.

**Q. 가족이 제 폰으로도 출석할 수 있나요?**
한 기기는 한 명에게 연결됩니다. 가족은 본인 기기를 쓰거나 키오스크에서 출석해 주세요.

**Q. "승인 대기 중"이라고 떠요.**
등록 승인제가 켜져 있는 경우입니다. 관리자가 승인하면 자동으로 출석까지 완료됩니다. 오래 걸리면 리더에게 말씀해 주세요.

**Q. 인터넷이 안 되는데 체크인을 눌렀어요.**
"오프라인 — 대기열에 저장됨"이 떴다면 걱정 마세요. 인터넷이 연결되는 순간 자동으로 출석 처리됩니다.

### 리더 / 새가족팀

**Q. 관리자 로그인이 안 돼요.**
- Google 로그인: 본인 이메일이 멤버 정보에 등록되어 있고 관리자 역할이 부여되어 있어야 합니다 → 최고관리자에게 확인 요청.
- 비밀번호 입장: ① 비밀번호 확인, ② **본인 기기가 본인 멤버에 연결**되어 있는지 확인(기기 탭에서 연결), ③ 역할 부여 여부 확인. 키오스크 명단(ROSTER) 기기로는 불가.

**Q. 다른 동산/부서 멤버가 안 보여요.**
리더·새가족팀은 지정된 부서·동산 범위만 봅니다. 범위 변경은 최고관리자에게 요청하세요. (여름 모드에는 대학부·청년부가 합동으로 보입니다)

**Q. 출석을 잘못 찍었어요. 지울 수 있나요?**
「멤버」 → 해당 멤버 → 출석 이력 펼치기 → 해당 날짜 삭제. 또는 「출석부」 로그에서 확인 후 같은 방법으로 삭제.

**Q. 지난주 출석을 빠뜨렸어요.**
「출석부」 → **일괄 출석** → 날짜 선택 → 멤버 선택 → 저장.

**Q. 같은 사람이 두 명으로 보여요.**
「멤버」에서 한쪽 카드 → **병합**. 출석 기록이 합쳐지고 한 명만 남습니다. 되돌릴 수 없으니 이름·기록을 꼭 확인 후 진행하세요.

**Q. "동산 이동" 버튼이 안 보이거나 안 돼요.**
새가족팀 역할이거나, 본인이 동산지기/부동산지기로 지정된 리더는 사용할 수 없습니다.

**Q. 출석부를 엑셀/PDF로 뽑고 싶어요.**
「출석부」 → **내보내기** → Excel / PDF / 카카오톡 요약 중 선택.

### 최고관리자

**Q. 출석 전체 삭제 요청이 왔는데 어디서 처리하나요?**
「관리자」 탭 하단의 삭제 요청 목록에서 **승인 후 삭제** 또는 **거절**. 승인 전 반드시 백업을 받으세요.

**Q. 실수로 데이터를 망쳤어요.**
최근 백업 파일이 있다면 「관리자」 → **복원**. 백업 시점 이후 기록은 사라지므로 신중히. 누가 무엇을 했는지는 **감사 로그**에서 확인할 수 있습니다.

**Q. 마지막 최고관리자를 제거하려니 안 돼요.**
의도된 안전장치입니다. 새 최고관리자를 먼저 추가한 뒤 제거하세요.

**Q. 여름이 끝났는데 동산이 이상해요.**
「설정」에서 여름 모드 OFF → 「동산」에서 부서별 동산 이름 확인 → 「멤버」 동산 일괄 이동으로 재배치.

### 공통

**Q. 화면이 영어로/한국어로 바뀌었어요.**
우측 상단 `EN`/`KO` 버튼으로 전환됩니다. 기기별로 저장됩니다.

**Q. 새로고침했더니 첫 화면으로 돌아갔어요.**
의도된 동작입니다(키오스크 화면만 새로고침 시 유지). 관리자 화면은 다시 로그인해 들어가세요.

**Q. 버그를 발견했어요 / 기능 제안이 있어요.**
임원(시스템 담당자)에게 화면 캡처와 함께 알려주세요. GitHub 저장소(shrlak/kccp) 이슈로도 접수 가능합니다.
